## 本次修正后的阶段规则

1. 当前模型步骤尚未输出正文时，实时显示接口返回的推理文字。
2. 第一段正文到达时立即清除推理，不等待它被归类为 commentary 或最终答案。
3. 工具接手、等待用户、停止、失败或会话结束时，同步清除推理状态。
4. 同一消息在正文之后到达的推理片段不重新打开预览；后续新的模型步骤可以再次显示新推理。
5. 只有仍处于推理阶段但停更时才采用 5 秒淡出。该计时不能延长到回答阶段。

上次的 DOM 测试错误地接受了“回答完成后仍等计时结束”的行为；本次改用第一段正文、工具接手与终态事件验收，检查状态已清除，而不仅检查 CSS 隐藏。
