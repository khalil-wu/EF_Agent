# EFAgent 结构

浏览器连接 Go 网关。网关管理会话、工作区、对话模型、工具循环和 SSE 事件；Python worker 完成数据读取、科学计算、绘图、资料检索与远程模型调用。

| 目录 | 职责 |
| --- | --- |
| `gateway/internal/agent` | 多轮工具执行、取消、持久化与上下文管理 |
| `gateway/internal/prompt` | 任务规则、领域约定、工作区与资料上下文 |
| `gateway/internal/server` | HTTP、上传、流式会话、文件与产物服务 |
| `src/eegagent/worker` | 脑电、视频、图片、文件与产物工具 |
| `src/eegagent/knowledge` | 文档分块、混合检索、图谱和来源定位 |
| `skills` | 按需加载的方法、选择原则与 API 说明 |
| `frontend/src` | React 对话状态、事件归并与增量渲染 |
| `frontend/bridge` | 两侧栏、输入器、工作区与产物面板 |

计算结果用 manifest 和 artifact 记录连接：输入事实、处理链、来源、时间轴、单位与输出文件可以追溯。对话区展示本次关键结果，产物面板保存完整目录。

进度采用接口返回的推理文字、模型公开回复、工具开始与结束事件和实际执行阶段。推理文字独立流式显示，停更 5 秒后淡出，不进入持久对话或最终回复。前端按稳定 ID 更新同一条记录；重新进入会话时从快照与事件游标续接。切换会话只取消浏览器订阅，后台分析继续运行。

科学测量由本地工具执行；专用情绪预测来自按输入契约登记的模型；模型对测量的解释单独保留证据与状态。领域 skill 提供方法建议，工作区协议提供本批数据事实，检索资料提供可读取的来源。
